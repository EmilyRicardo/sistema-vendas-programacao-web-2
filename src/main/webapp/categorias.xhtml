Hierarquia segura

Escolha uma categoria pai para criar subcategorias. O sistema impede que uma categoria se torne descendente dela mesma e não permite excluir categorias que ainda tenham filhos ou produtos.

Selecione “Categoria raiz” para não ter uma categoria pai.
